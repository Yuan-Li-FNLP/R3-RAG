## 🎯 语言检测

脚本会**自动检测**每个文件的语言：

```python
德语特征词: der, die, das, und, ist, von, zu, mit, für, über
英语特征词: the, and, is, to, of, in, for, with, that, are

if 德语特征词数量 > 英语特征词数量:
    → 标记为德语 (🇩🇪)
else:
    → 标记为英语 (🇬🇧)
```

**示例**：
```
文本: "Die Vorlesung behandelt künstliche Intelligenz..."
检测: 🇩🇪 德语 (因为包含 die, künstliche 等)

文本: "This course covers artificial intelligence..."
检测: 🇬🇧 英语 (因为包含 this, course, covers 等)
```

## 🔨 第4步：切分和索引

清洗完成后，使用之前的智能切分脚本：

```bash
# 合并所有清洗后的文件
cat cleaned_*.json > all_cleaned.json

# 使用智能切分器
python3 smart_chunker_for_tum.py \
    --input all_cleaned.json \
    --output final_corpus.jsonl

# 构建多语言索引
python3 -m flashrag.retriever.index_builder \
    --retrieval_method e5 \
    --model_path intfloat/multilingual-e5-base \
    --corpus_path final_corpus.jsonl \
    --save_dir ../../indexes/tum_multilingual_kb \
    --batch_size 64
```

## 💡 常见问题

### Q1: HTML文件太大（包含很多无用内容）怎么办？
**A**: 脚本会自动去除导航、菜单、登录按钮等。如果还是太大，可以手动调整清洗规则。

### Q2: 语言检测不准确怎么办？
**A**: 如果文档很短或混合语言，可能检测不准。你可以手动指定语言：
```python
cleaner.clean(text, language='de', format_type='pdf')
```

### Q3: PDF有密码怎么办？
**A**: 先用工具解密：
```bash
qpdf --decrypt --password=yourpassword input.pdf output.pdf
```

### Q4: 如何处理PPT/PPTX？
**A**: 转换成PDF：
```bash
libreoffice --headless --convert-to pdf *.pptx
```
