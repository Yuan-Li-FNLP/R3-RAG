## ✂️ **第4步：智能切分（关键！）**

这是关键步骤！不同类型的文档用不同的切分策略。

创建切分脚本：`process_all_types.py`

```python
import json
from smart_chunker_for_tum import TUMDocumentChunker

chunker = TUMDocumentChunker()

# ==========================================
# 1. 课程介绍（200门）- 不切分
# ==========================================
print("处理课程介绍...")
with open('cleaned_course_intros.json', 'r', encoding='utf-8') as f:
    course_intros = json.load(f)

for doc in course_intros:
    # 从文件名提取课程代码（如 IN2064_intro.pdf → IN2064）
    filename = doc['source_file']
    course_code = filename.split('_')[0] if '_' in filename else filename.replace('.pdf', '')

    chunker.process_document(
        text=doc['cleaned_text'],
        doc_type='course_intro',
        doc_id=course_code
    )

print(f"✅ 课程介绍处理完成")

# ==========================================
# 2. 模块规划（8个）- 按模块切分
# ==========================================
print("\n处理模块规划...")
with open('cleaned_module_plans.json', 'r', encoding='utf-8') as f:
    module_plans = json.load(f)

for doc in module_plans:
    module_name = doc['source_file'].replace('.pdf', '')

    chunker.process_document(
        text=doc['cleaned_text'],
        doc_type='module_plan',
        doc_id=module_name
    )

print(f"✅ 模块规划处理完成")

# ==========================================
# 3. 课程讲义（30门）- 智能章节切分
# ==========================================
# 策略：
# 1. 优先按章节结构切分（Chapter 1, Kapitel 1等）
# 2. 如果单个章节>3000字符，章节内二次切分
# 3. 如果没有章节结构，回退到1500字符切分
print("\n处理课程讲义...")
with open('cleaned_lectures.json', 'r', encoding='utf-8') as f:
    lectures = json.load(f)

for doc in lectures:
    course_code = doc['source_file'].split('_')[0]

    chunker.process_document(
        text=doc['cleaned_text'],
        doc_type='lecture',
        doc_id=course_code
    )

print(f"✅ 课程讲义处理完成")

# ==========================================
# 4. 练习题（30门）- 按题切分
# ==========================================
print("\n处理练习题...")
with open('cleaned_exercises.json', 'r', encoding='utf-8') as f:
    exercises = json.load(f)

for doc in exercises:
    filename = doc['source_file']
    # 如 IN2064_exercise01.pdf
    course_code = filename.split('_')[0]
    exercise_id = filename.replace('.pdf', '')

    chunker.process_document(
        text=doc['cleaned_text'],
        doc_type='exercise',
        doc_id=exercise_id
    )

print(f"✅ 练习题处理完成")

# ==========================================
# 5. Script（30门）- 标准切分
# ==========================================
print("\n处理Script...")
with open('cleaned_scripts.json', 'r', encoding='utf-8') as f:
    scripts = json.load(f)

for doc in scripts:
    course_code = doc['source_file'].split('_')[0]

    chunker.process_document(
        text=doc['cleaned_text'],
        doc_type='script',
        doc_id=course_code
    )

print(f"✅ Script处理完成")

# ==========================================
# 6. 参考文献（30门）- 不切分或按条目切
# ==========================================
print("\n处理参考文献...")
with open('cleaned_references.json', 'r', encoding='utf-8') as f:
    references = json.load(f)

for doc in references:
    course_code = doc['source_file'].split('_')[0]

    chunker.process_document(
        text=doc['cleaned_text'],
        doc_type='references',
        doc_id=course_code
    )

print(f"✅ 参考文献处理完成")

# ==========================================
# 7. 项目文档（2个）- 按章节切分
# ==========================================
print("\n处理项目文档...")
with open('cleaned_projects.json', 'r', encoding='utf-8') as f:
    projects = json.load(f)

for doc in projects:
    project_name = doc['source_file'].replace('.pdf', '')

    chunker.process_document(
        text=doc['cleaned_text'],
        doc_type='project',
        doc_id=project_name
    )

print(f"✅ 项目文档处理完成")

# ==========================================
# 导出
# ==========================================
chunker.export_to_jsonl('final_corpus.jsonl')
chunker.print_statistics()
```

## ⚙️ 不同切分策略的原因

### 1. 课程介绍（200门）- **不切分** ❌

**原因**：
- 每个介绍很短（<1000字符）
- 信息紧密相关（课程代码、学分、先修课程）
- 切分会破坏完整性

**示例**：
```
IN2064 - Introduction to AI
ECTS: 6
Lecturer: Prof. Müller
Prerequisites: IN0001, MA0001
Description: This course...
```
→ 一个块就够了

---

### 2. 模块规划（8个）- **按模块切分** ✂️

**原因**：
- 每个模块相对独立
- 学生可能查询"Kernmodule需要多少学分"
- 模块之间信息不相关

**示例**：
```
Modul 1: Kernmodule (60 ECTS)
- IN2064 (6 ECTS)
- IN2118 (6 ECTS)
...

Modul 2: Vertiefungsmodule (30 ECTS)
...
```
→ 每个模块一个块

---

### 3. 课程讲义（30门）- **智能章节切分** 📚

**策略**：
1. **优先按章节结构切分**（识别 Chapter, Kapitel, Section 等）
2. **如果单个章节>3000字符**，在章节内部二次切分
3. **如果没有章节结构**，回退到1500字符标准切分

**原因**：
- 讲义很长（几万字符），但有清晰的章节结构
- 按章节切分保持语义完整性
- 每个块包含完整的知识主题
- 更易检索和理解

**示例**：
```
讲义：包含 Kapitel 1, Kapitel 2, Kapitel 3...
→ 块1: Kapitel 1: Suchverfahren (2500字符) - 完整章节
→ 块2: Kapitel 2: Heuristiken (1800字符) - 完整章节
→ 块3: Kapitel 3: Machine Learning (4200字符) - 章节太长
   → 块3a: Kapitel 3 第一部分 (1500字符)
   → 块3b: Kapitel 3 第二部分 (1500字符)
   → 块3c: Kapitel 3 第三部分 (1200字符)
```

---

### 4. 练习题（30门）- **按题切分** 📝

**原因**：
- 每道题是独立的
- 学生可能查询"Aufgabe 3怎么做"
- 按题切分最自然

**示例**：
```
Aufgabe 1: Implementieren Sie BFS... (500字符)
→ 块1

Aufgabe 2: Zeigen Sie... (800字符)
→ 块2

Aufgabe 3: ... (1200字符)
→ 块3
```

---

### 5. Script（30门）- **标准切分（1500字符）** ✅

**原因**：
- Script类似讲义，是长文档
- 结构化内容
- 需要标准切分

---

### 6. 参考文献（30门）- **不切分** ❌

**原因**：
- 通常不长（<2000字符）
- 是列表形式
- 整体信息更有用

**示例**：
```
Literatur:
[1] Russell, S. (2020). AI...
[2] Mitchell, T. (1997). ML...
...
```
→ 一个块

---

### 7. 项目文档（2个）- **按章节切分** 📑

**原因**：
- 有明确的章节结构
- 学生可能查询"项目评分标准是什么"
- 按章节切分便于检索

**示例**：
```
1. Projektziele
2. Anforderungen
3. Bewertungskriterien
```
→ 每章一个块

---

## 🎯 总结：你的切分策略表

| 文档类型 | 切分方式 | 块大小 | 原因 |
|---------|---------|-------|------|
| 课程介绍 | ❌ 不切分 | 整个文档 | 太短，切分无意义 |
| 模块规划 | ✂️ 按模块 | 1个模块 | 模块独立 |
| 课程讲义 | 📚 智能章节切分 | 1章节（或1500字符） | 保持章节完整性 |
| 练习题 | 📝 按题切分 | 1道题 | 题目独立 |
| Script | ✅ 标准切分 | 1500字符 | 类似讲义 |
| 参考文献 | ❌ 不切分 | 整个文档 | 列表，不长 |
| 项目文档 | 📑 按章节 | 1个章节 | 章节独立 |
